📘 How to Use

🔢 Matrix

  1. Press SHIFT → then 7 (MAT label) to open Matrix modal.
  2. Select Save As: MatA or MatB.
  3. Set Dim (rows × cols): 2×2 or 3×3.
  4. Click Grid to generate input cells.
  5. Fill in values using keyboard or arrow keys.
  6. Click Save Object — MatA or MatB appears on display.
  7. Use + − × between MatA and MatB.
  8. Repeat for second matrix (MatB).
  9. Press = to calculate.
Example: MatA + MatB = MatA * MatB =
⚠️ For addition/subtraction, both matrices must have same dimensions. For multiplication, cols of MatA must equal rows of MatB.

➡️ Vector

  1. Press SHIFT → then 8 (VCT label) to open Vector modal.
  2. Select Save As: VctA or VctB.
  3. Choose Dimensions: 2D (X,Y) or 3D (X,Y,Z).
  4. Click Grid to generate input fields.
  5. Fill in X, Y (and Z for 3D) values.
  6. Click Save Object — VctA or VctB appears on display.
  7. Use + − for vector addition/subtraction.
  8. Use × for dot product.
  9. Repeat for second vector (VctB).
  10. Press = to calculate.
Example: VctA + VctB = VctA * VctB =
⚠️ Both vectors must have the same number of dimensions for operations.

📊 Statistics

  1. Type your data values separated by commas on the display.
  2. Example: 2,4,6,8,10
  3. Press SHIFT to activate SHIFT mode.
  4. Press 4 for S-SUM functions.
  5. Press 5 for S-VAR functions.
  6. Result shows instantly — no need to press =.
S-SUM functions (SHIFT → 4): Σx  — Sum of all values Σx² — Sum of squares n   — Count of values
S-VAR functions (SHIFT → 5): x̄   — Mean (average) σx  — Population std dev sx  — Sample std dev minX / maxX
⚠️ Enter at least 2 comma-separated values on display before pressing SHIFT → S-SUM or S-VAR.

📈 Distribution

  1. Press SHIFT → then 6 (DISTR) to open Distribution modal.
  2. Choose Standard Normal (Z) or General Normal (X, μ, σ).
  3. Enter the required value(s).
  4. Click Solve PD for Probability Density.
  5. Click Solve CDF for Cumulative Distribution.
PD: f(z) = (1/√2π) × e^(−z²/2)
CDF: P(Z ≤ z) — area under curve

🔣 Permutation & Combination

  1. Enter the value of n on the display.
  2. Press SHIFT to activate SHIFT mode.
  3. Press AC for nPr (Permutation).
  4. Press C for nCr (Combination).
  5. Enter the value of r.
  6. Press = to calculate the result.
Example (nPr): 5 → SHIFT → AC → 3 → = Result: 60  (5P3 = 60)
Example (nCr): 5 → SHIFT → C → 3 → = Result: 10  (5C3 = 10)
⚠️ n and r must be non-negative integers, and r must be less than or equal to n.
