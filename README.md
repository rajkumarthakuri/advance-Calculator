# 🧮 Advanced Calculator

A feature-rich scientific calculator built with HTML, CSS, and JavaScript — supporting standard arithmetic, scientific functions, SHIFT-activated operations, and statistical computations.

---

## Features

### Basic Operations
- Addition, Subtraction, Multiplication, Division
- Percentage, sign toggle (±), decimal support
- Clear (AC) and backspace

### Scientific Functions
- Trigonometry: `sin`, `cos`, `tan` (and inverses: `sin⁻¹`, `cos⁻¹`, `tan⁻¹`)
- Logarithms: `log` (base 10), `ln` (natural log)
- Powers & Roots: `x²`, `x³`, `xʸ`, `√`, `∛`
- Constants: `π`, `e`
- Factorial: `n!`
- Reciprocal: `1/x`
- Exponential: `EXP`

### SHIFT Mode
- Activates inverse/alternate functions (e.g. `sin` → `sin⁻¹`)
- Toggle on/off with the **SHIFT** button

### Statistical Operations
- `S-SUM` — Sum of entered values
- Additional stat functions via SHIFT row

### Angle Modes
- Switch between **DEG** (degrees) and **RAD** (radians) for trig calculations

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rajkumarthakuri/advancedCalculator.git
   ```

2. Navigate into the folder:
   ```bash
   cd advancedCalculator
   ```

3. Open in browser:
   ```bash
   # Simply open index.html in your browser
   start index.html       # Windows
   open index.html        # macOS
   xdg-open index.html    # Linux
   ```

No dependencies. No install. Just open and use.
